# Gestión de luminarias

Sistema de gestión interno para una empresa de iluminación: controla componentes, fabricación, stock y órdenes de trabajo.

> **Proyecto privado de uso empresarial. Todos los derechos reservados.** Prohibida su copia, redistribución o uso sin autorización (ver [LICENSE](./LICENSE)).

## Qué hace

- **Dashboard** con producción, stock y órdenes abiertas.
- **Componentes y recetas (BOM)** de cada luminaria.
- **Fabricación** con descuento automático de stock.
- **Movimientos, vales y remitos** de ingreso y egreso.
- **Sensores y fuentes, luminarias, herramientas y materiales de obra**.
- **Clientes, proveedores, presupuestos y órdenes de trabajo**.
- **Proyectos de fábrica, reportes y auditoría**.
- **Roles de usuario** con permisos diferenciados.

## Tecnologías

Next.js · React · TypeScript · MongoDB (Mongoose) · NextAuth · Tailwind CSS · shadcn/ui
